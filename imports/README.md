## 后续文件

- `*.pdf` / `*.docx` 研报原文；
- `*.xlsx` / `*.csv` 研报清单或结构化跟踪表；
- `*.json` 已有系统导出的结构化数据。

建议同时提供：

1. 研报文件或下载链接；
2. 覆盖标的的日行情（股票代码、日期、收盘价）；
3. 基准指数行情（如沪深300）；
4. 字段说明或样例文件。

当前版本已支持结构化 JSON 入库，尚未接入 PDF/Excel 自动解析器。
